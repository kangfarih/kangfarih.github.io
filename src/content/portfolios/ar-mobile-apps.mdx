An augmented reality apps as simulator of [First4Figures](https://www.first4figures.com/) products.  
I worked on this project as part of the [Plexus.id](http://plexus.id) team. It includes a mobile app with AR features and an admin web app to manage content.

* * *

### Overview

*   Role: Front End Programmer
*   Type: Mobile App (User), Web App (Admin)
*   Technology: Unity (User), Web (Admin)
*   Features:
    *   Augmented reality product visualization
    *   Browse items, download assets, capture photos/videos
    *   Admin panel to create/update/delete app data

### Role

I collaborated with backend engineers and a UI designer as part of the front-end team. I was responsible for implementing and maintaining the app features across both the mobile client and the admin web panel.
