An interactive web video player with clickable tags/hotspots. I built this as a freelance project for [DreamTechnology](http://dreamtechnology.co.id/) using vanilla JavaScript and jQuery.

* * *

### Overview

*   Role: Front End Programmer
*   Type: Web App
*   Technology: jQuery, Vanilla JavaScript
*   Release: [Website](https://sdm.kemdikbud.go.id/video-interaktif/)
*   Features:
    *   Custom video controls
    *   Clickable in-video tag links
    *   Fullscreen support
    *   Safari and iOS compatibility

### Role

As the front-end developer, I implemented and maintained the features, ensuring the player worked reliably across different screen sizes and browsers.
