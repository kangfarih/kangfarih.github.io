This is a project about an audio player with encrypted data to play.  
I built two mobile applications as a freelance project: a user app and an admin app. Both are built with React Native.

* * *

### Overview

*   Role: Front End Programmer
*   Type: Mobile Apps (User and Admin)
*   Technology: React Native
*   Release: [Google Play](https://play.google.com/store/apps/details?id=com.ajtencryptedplayer)
*   Features:
    *   Download and audio playback controls (play/pause/seek)
    *   Encryption/decryption flow for protected audio content
    *   Admin app to upload and delete encrypted audio data

### Role

I collaborated with a backend engineer. As the front-end programmer, I implemented and maintained the features for both the user and admin mobile apps.
