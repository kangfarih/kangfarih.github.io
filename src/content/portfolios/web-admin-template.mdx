This project demonstrates my experience building an admin dashboard, based on work I did as part of the [Plexus.id](http://plexus.id) team.  
It uses a Bootstrap-based template and vanilla JavaScript for practical, easy-to-extend UI patterns.

* * *

### Overview

*   Role: Developer
*   Type: Web App, REST API
*   Technology:
    *   Backend:
        *   Express.js
        *   MongoDB
    *   Frontend:
        *   Bootstrap admin template: [Gentelella](https://github.com/ColorlibHQ/gentelella.git)
        *   jQuery
        *   DataTables
        *   Parsley.js
        *   Font Awesome
        *   Summernote
*   Repo: [GitHub](https://github.com/kangfarih/portfolio-web-admin)
*   Features:
    *   Demo data and sample admin screens
    *   Work-in-progress enhancements

### Role

I built this project as a portfolio demo and learning sandbox for admin dashboard patterns.
