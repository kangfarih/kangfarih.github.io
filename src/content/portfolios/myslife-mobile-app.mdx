A mobile app of [MySLife](https://myslife.co/) products.  
I worked on this project as part of the [Creatella](https://creatella.ventures/) team. It includes a user-facing mobile app and an admin web app to manage content and operations.

* * *

### Overview

*   Role: Front End Programmer
*   Type: Mobile App (User), Web App (Admin)
*   Technology: React Native (Mobile), React (Web)
*   Release: [Google Play](https://play.google.com/store/apps/details?id=com.myslifeproject), [App Store](https://apps.apple.com/fr/app/my-s-life/id1582741132)
*   Features:
    *   Feed browsing and posting
    *   Profile and chat
    *   Content and subscription flows
    *   Admin web panel

### Role

I collaborated with backend engineers and a UI designer as part of the front-end team. During development, I built and shipped features such as categories, profile, and chat. After release, I continued maintaining the app and delivering feature updates, including content and subscription improvements.
