A mobile apps for reading and buy a comic made by [Ragasukma](http://ragasukma.com).  
I worked on this project as part of the [Plexus.id](http://plexus.id) team.  
The application was released on Google Play.  
It includes a mobile app for end users and a web admin panel for content management.

* * *

### Overview

*   Role: Front End Programmer
*   Type: Mobile App (User), Web App (Admin)
*   Technology: React Native (User), Web (Admin)
*   Release: [Google Play](https://play.google.com/store/apps/details?id=id.plexus.ragasukmacomicapp)
*   Features:
    *   User: login/logout, profile
    *   Reader: read comics, zoom in/out, offline reading, favorites
    *   Social: comments and ratings
    *   Transactions: cart and payment flow
    *   Other: highlights, articles, image downloads
    *   Admin panel to create/update/delete app data

### Role

I collaborated with backend engineers and a UI designer. As part of the front-end team, I implemented and maintained the app features across both the mobile app and the admin web panel.
